# T-003 — Add `docs/README.md` and make the bootstrap trigger survive it

## Description
`docs/README.md` explains how the living-memory folder is used. It was left out of the seed commit because any `/docs` change needs six-agent consensus. Reviewing it showed that its presence makes `/docs` non-empty, so the bootstrap trigger ("`/docs` is empty or missing") would never fire. This task adds the file and rewords the trigger to "no `contracts.md` yet".

**Tier:** Risky (a `/docs/*` edit, plus `AGENTS.md` and `.claude/agents/review-coordinator.md`).

## Acceptance criteria
1. [ ] `docs/README.md` exists and every claim it makes about this repository is checkable against `AGENTS.md`, `.githooks/`, `scripts/` or `tasks/` (§ 6.0(1)(2)).
2. [ ] It states whether it is descriptive or forward-looking, records how it was verified, and ends with an "update-this-doc-when" footer (§ 6.0(1)(5)(6)).
3. [ ] It says accurately what the hook checks, what CI checks, and what neither checks, for the consensus trailer.
4. [ ] It contains no unreplaced stack placeholder. The one match for the gate's pattern is the anti-pattern line that names the convention, so the file stays in `.placeholder-allow`.
5. [ ] `AGENTS.md` (Quick Summary item 1, § 0 Step 3, § 6), `.claude/agents/review-coordinator.md`, `CLAUDE.md` and the root `README.md` define "not yet bootstrapped" by the single test "there is no `docs/contracts.md`", so a `/docs` holding only this README, or an adopted project's existing `docs/` content, still triggers the bootstrap.
6. [ ] All 6 agents sign off; the commit carries `unanimous-consensus: T-003`.

## Out of scope
- Changing what the `commit-msg` hook or `scripts/ci-checks.sh` enforce. The reviewers found the hook does not check deletion-only `/docs` commits while CI does; that divergence is recorded here and needs its own Risky-tier task.
- Writing any of the bootstrap docs (`T-001`).
