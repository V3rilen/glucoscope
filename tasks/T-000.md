# T-000 — Housekeeping

## Description
The standing task that Trivial-tier commits reference, so every commit carries a task ID without a new task file for each typo. It never closes.

## What may reference T-000
Only changes that qualify as **Trivial** under `AGENTS.md` § 5: typo fixes, dependency lockfile bumps, comment-only edits, formatter-only churn, generated-file refreshes.

## What may not
Any behavior change, user-visible change, new dependency, schema change, security-relevant change, or any change to `/docs/*`, `.claude/agents/*.md`, `.githooks/`, `scripts/` or `.github/`. Those get their own task and their tier's review. When in doubt, open a task.

## Notes
- No plan approval and no agent review at this tier. Hooks and CI still run, and the change still goes through a branch and a pull request.
- Don't log individual trivial commits here; `git log --grep T-000` is the record.
