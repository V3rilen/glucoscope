# T-001.2 — Write `architecture.md`

**Parent:** [T-001](./T-001.md) · **Owner:** architect (verifier reviews the testing and deployment sections)

## Description
The system overview for `Glucoscope` on `a self-hosted machine behind Cloudflare`, in one file with four sections. Split a section into its own file only when it outgrows the page.

## Acceptance criteria
- [ ] `/docs/architecture.md` exists.
- [ ] **Overview** — services/components and their responsibilities, data flow (diagram or textual equivalent), trust boundaries, identity & secrets approach, failure modes, high-level cost shape.
- [ ] Names **every** external dependency the system relies on (exhaustive, per `AGENTS.md` § 6.0(3); reconciled with `contracts.md`).
- [ ] **Stack** — language(s), frameworks, database, hosting platform, secret manager, package manager, each with a short "why this" and the alternatives considered. Marks any load-bearing dependency (expensive to replace) and notes license posture for major dependencies.
- [ ] **Testing** — test levels in use (unit, integration, contract, end-to-end), the tooling (`the built-in Node test runner (node:test)`), how to run each locally and in CI, the test-data approach, and the flake policy: flakes are bugs, fix or delete.
- [ ] **Testing** documents the **regression-safety check** (`AGENTS.md` § 7): how to map a `contracts.md` entry to the tests that guard it, and what to run before committing a contract-touching change.
- [ ] **Deployment** — environments and how they differ, the Continuous Integration stages and required checks, how a release reaches production, and the rollback path — tested, not theoretical.
- [ ] Grounded in real code/infra with paths cited; any unconfirmed fact written `UNKNOWN — needs human confirmation`, never guessed (§ 6.0(1)(2)). If greenfield, marked **forward-looking**.
- [ ] Verification method recorded (how the component/dependency map was checked against the repo), per § 6.0(5).
- [ ] Includes an "update-this-doc-when" footer.
- [ ] No unreplaced `[insert … here]` placeholders.
- [ ] All 6 agents have signed off (recorded in `T-001.5`).
