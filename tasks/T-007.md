# T-007 — README "Setup" section

## Description
`AGENTS.md` line 7 ("Follow the Setup section of `README.md`") and line 218 ("Require the check in branch protection (`README.md`, Setup)") point to a Setup section of the root `README.md`, but there isn't one. It looks like it was lost when the starter was adopted (T-000/PR #3). A new contributor or agent following `AGENTS.md` finds no instructions for installing the hooks or requiring the CI checks. Found while planning T-004.

## Acceptance criteria
- [ ] `README.md` has a Setup section covering:
  - `npm install`, and `npm test` (T-004)
  - `sh scripts/setup-hooks.sh`, the one-time hook install
  - requiring both CI checks on `main` (as the `protection-main` ruleset does, `docs/architecture.md` § 7)
- [ ] Or `AGENTS.md` points somewhere else that has these steps. `AGENTS.md` is not under `/docs`, but it is process-critical, so pick the tier with that in mind.
- [ ] Every link from `AGENTS.md` to the README resolves.
